# Submission package — 2E-MVRP-SS certified-bound paper

This package was revised after three rounds of detailed referee-style review (findings #1–#8, then a
second and third round; decisions d798–d813). The manuscript compiles (43 pp); the certification
proofs were corrected (the ε|C| proof dualizes the finite variable upper bounds; the ng proof keeps
the LP ordering between complete optima and does not assert exact equality under the −ε stopping
rule) and the two constructive mapping proofs (floor and width) now map to the **retained** column
variants and to coarse **paths** with explicit waiting; the displayed lower bounds are rounded
**down** to valid lower bounds; the production pricer audit was extended (completion-bound prune
on/off with label dominance always on, absolute tolerance, exhausted = failure, extra ng walks, duals
at the −ε threshold); `third_party_manifest.json` ships so `fetch_karademir.py --verify` runs; and the
layout below mirrors the repository so the validation scripts run as written. Author sign-off items
remain (below).

## Reproducing the checks (run from this root; Python 3.10, Gurobi, numpy/scipy)

```
python analysis/cert_audit.py                  # area 5: per-cell certificate consistency
python analysis/reverify_reported.py           # area 6: joint re-verification + incumbent manifest
python analysis/ab_formula_check.py            # area 7: AB4 reproduction + components
python analysis/floor_relax_check.py --cells C201,R201,RC201,C204,R205 --size 10   # area 4: floor relaxation
python analysis/fastpricer_check.py                                                # area 4: production FastPricer (defaults to R205, which has extra ng walks)
python analysis/enum_price_check.py --cell C201 --size 10 --n-cust 6               # area 4: enumeration
python analysis/tab_percell_grid.py                                                # per-cell appendix table (floored valid bounds)
python analysis/floor_map_check.py  --cells C201,R201,RC201 --size 10 --n-cust 6   # area 2: floor LP<=IP
python analysis/build_manuscript.py --name main4                                   # compile the PDF
```

`cert_audit` and `reverify_reported` read the packaged `runs/oracle/` artifacts and run with no solver.
The enumeration/floor/FastPricer checks and the manuscript build need Gurobi and the benchmark
instances; those are regenerated by the predecessors' released generator and retrieved by
`fetch_karademir.py` at a pinned commit, each verified against a recorded SHA-256 digest (their
repository carries no licence, so none of it is redistributed here).
